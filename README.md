# Mounta

Cloud PMS & self check-in for small stays: Airbnb hosts, hostels and boutique hotels.

## What is here

- `index.html`, `emblem.png`, `logo-light.png`: the marketing website, a static page. Vercel serves it from the repository root.

The Mounta program (admin, guest check-in, stay pass) will be added to this repository as a Next.js app, built from the SANN Hostel OS codebase with SANN-specific parts removed and support for many customers added.

## Deploy

Vercel deploys `main` to production on every push. Pull requests get their own preview link.
